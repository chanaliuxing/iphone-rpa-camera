# iPhone 7 Plus G0 真实验收（公开脱敏版）

结论：**G0_MAC_CAMERA_GO**；**G0_WINDOWS_NOT_RUN**。

## 环境与构建

2026-10-26 现场测试。iPhone 7 Plus / iOS 15.8.6、Mac macOS 27.0.1；App 最低 iOS 15.0 / arm64。现场经用户授权修复小屏幕滚动问题，并通过 iLoader 2.4.0 更新安装，用户确认页面可滚动。精确账号、设备标识、IP、路径和采集时刻均已移除。

## 故障与修复

初期服务停止、端口连接失败；现场发现固定 VStack 页面无法上下滚动、控件超出屏幕。最小修复为竖向 ScrollView 和移除末尾 Spacer；Swift 语法解析与 archive 成功，获得明确更新授权后才签名覆盖安装。拍照与鉴权协议保持不变。

测试执行者曾错误转换 Token 大小写，导致一次 403；改回完全一致的原始大小写后成功，没有放宽服务端鉴权。后续停止、恢复和错误 Token 检查均按真实结果记录。

## 证据与适用边界

原始照片和原始日志由设备持有人保留在本地，因为图片包含聊天、屏幕内容和 Token，不公开上传。公开仓库只发布 docs/evidence/mac_g0_summary.json 中的派生统计，因此本报告是现场验收记录，并非读者可从仓库原图独立复核的公共证据集。

现有真实照片可作为后续屏幕 OCR 的候选输入；部分汉字可辨，但有反光、倾斜和部分软焦。未运行微信 OCR、未测识别成功率、未证明优于 USB 摄像头，未接入微信 Reader 或修改 ESP32。

Mac 核心 GO 条件已满足。Windows 和生产可靠性仍需独立实测，不能由 Mac POC 外推。
