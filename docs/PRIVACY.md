# 公开版隐私处理

公开仓库由明确文件白名单创建，没有导入原始工作目录的 Git 历史。

包含：自研 Swift / Python 源码、原有单元测试、通用构建脚本、脱敏安装/协议/验收文档、仅数值的真机统计。

排除：真实 Token、Apple Account 与其他账号、密码、签名证书/密钥/描述文件、设备 UDID/ECID、MAC 地址、本机用户名和绝对路径、实际局域网地址、原始照片/视频、原始设备日志、原始响应头/UUID、编译产物、第三方安装器和打包缓存。文档中私有地址仅使用统一示例。

现场原始照片含屏幕聊天与可识别内容，因此只在原本本地目录保存，不随仓库发布。统计数据属于经过筛选的派生证据，读者无法仅凭公开仓库独立核实原图内容；报告对此明确保留限制。

.gitignore 防止常见秘密、签名材料、照片和本地输出被常规 git add 收集；它不能替代发布前检查。后续贡献同样应使用虚构地址和样例标识，不上传真实凭据。

App 的 Token 是持久化随机值，未实现自动过期。免费签名的 7 天有效期不等于 Token 自动失效。HTTP 仅适用于可信 LAN；不要开放公网端口。
